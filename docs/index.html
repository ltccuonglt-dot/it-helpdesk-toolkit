🩺 Quét lỗi trên máy

Trình duyệt không thể tự quét hệ thống Windows (giới hạn bảo mật). Chạy script PowerShell scripts/Scan-System.ps1 trên máy cần kiểm tra (quyền Administrator), script sẽ xuất file scan-result.json. Tải file đó lên đây để tự động khớp với cơ sở dữ liệu lỗi.
